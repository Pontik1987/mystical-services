# 💼 Mystical Services — платформа услуг на Flask

**Mystical Services** — полноценная платформа для мастеров и их клиентов. **70+ фич**: от прайс-листа и онлайн-записи до гибкого расписания, портфолио и отзывов.

## ✨ Возможности (70+ фич)

### 💼 Для мастеров
- 📄 **Прайс-лист** — услуги с ценой, длительностью, категорией
- 🕐 **Гибкое расписание** — несколько интервалов на день (утро 30 мин, день 60 мин)
- 📅 **Онлайн-запись** — клиенты бронируют свободные слоты
- 🔄 **Перенос записи** — мастер меняет дату/время
- ✅ **Отметка «Выполнено»** — после визита клиента
- 📸 **Портфолио** — галерея работ с фото и описанием
- ⭐ **Отзывы** — оценки 1-5, средний рейтинг, распределение
- 💰 **Донаты** — приём звёзд ⭐ от благодарных клиентов

### 👤 Для клиентов
- 🔍 **Поиск мастеров** — по категории, городу
- 📄 **Страница мастера** — услуги, портфолио, отзывы
- 📅 **Календарь слотов** — свободные (фиолетовые) / занятые (серые)
- 💬 **Чаты** — общение с мастером
- ⭐ **Отзывы** — после выполненной записи
- 📖 **Истории и Клипы** — как в Instagram

### 🎨 Интерфейс
- 🌙 **Тёмная/светлая тема**
- 📱 **Адаптив** под мобильные
- 😀 **Эмодзи-пикер** (~600 эмодзи)
- 🤖 **AI-ассистент** — анализ постов
- 🎬 **Истории и Клипы**
- 📊 **Статистика** — графики активности
- 🔍 **Расширенный поиск** — фильтры по типу, дате, сортировке

### 📱 PWA
- 📲 Установка как приложение на телефон
- ⚡ Service Worker для оффлайн-кеша
- 🖼 Кастомные иконки

## 🎯 Как это работает

### Мастер:
1. Регистрируется
2. Настраивает **расписание** (дни, часы, интервалы)
3. Добавляет **услуги** (название, цена, длительность)
4. Загружает **портфолио** (фото работ)
5. Получает **записи** от клиентов
6. Подтверждает / переносит / отмечает «Выполнено»
7. Получает **отзывы** и **донаты**

### Клиент:
1. Находит мастера (поиск, профиль)
2. Видит **услуги**, **портфолио**, **отзывы**
3. Выбирает **свободный слот** в календаре
4. Записывается
5. После визита — оставляет **отзыв**
